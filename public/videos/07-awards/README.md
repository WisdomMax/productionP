# P LAB Creator Awards

이 폴더는 Production P의 회사 수상 실적보다 P LAB 교육생·후계 창작자들의
출품과 성과를 소개하기 위한 공간입니다.

- `submissions/`: P LAB 창작자의 공모전·영화제 출품 예정 또는 심사 중인 작품
- `winners/`: P LAB 창작자의 수상·본선 진출·영화제 공식 선정작

수상 결과가 확정되면 영상을 `submissions`에서 해당 폴더로 이동합니다.

## 홈페이지 표기 원칙

교육생의 개인 이름은 홈페이지에 표시하지 않습니다. 모든 공모전 작품은 다음
형식으로 소개합니다.

```text
작품명
P LAB 교육생 작품
2026 AI 영상 공모전
본선 진출
```

Production P가 실제 제작 주체가 아닌 경우 `PRODUCED BY PRODUCTION P`라고
표기하지 않습니다. 작품 성격에 맞춰 아래 한국어 표현을 사용합니다.

- `P LAB 교육생 작품`
- `P LAB 교육 과정 출품작`
- `P LAB 멘토링 작품`
- `P LAB에서 성장한 창작자들의 작품`

영문 이름, 한글 이름, 기수와 같은 개인 식별 정보는 카드와 상세 페이지 모두에서
노출하지 않습니다.

## 작품별로 함께 기록할 정보

- 작품명
- 홈페이지 표시 문구: `P LAB 교육생 작품`
- 내부 관리용 과정 정보
- 출품 공모전·영화제
- 출품 연도
- 현재 상태: 출품 / 본선 / 공식 선정 / 수상
- 수상명
- Production P의 역할: 교육 / 멘토링 / 큐레이션 / 공동 제작

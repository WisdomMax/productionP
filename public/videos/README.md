# Production P Video Library

웹사이트에서 사용할 영상은 아래 카테고리에 넣습니다.

## 폴더 구조

- `00-hero-depth/source/`: Depth 효과를 적용할 원본 MP4
- `00-hero-depth/depth/`: 원본에서 생성한 흑백 Depth 영상
- `00-hero-depth/web/`: 홈페이지용으로 압축·결합한 최종 영상
- `01-commercial/`: 광고·기업 홍보 영상
- `02-brand-film/`: 브랜드 필름
- `03-product/`: 제품·패션·F&B·테크 영상
- `04-film-content/`: 영화·내러티브·소셜 콘텐츠
- `05-p-lab/`: P LAB 및 실험 영상
- `06-animation/`: 2D·3D·모션그래픽·캐릭터 애니메이션
- `07-awards/submissions/`: P LAB 교육생·후계 창작자의 공모전 출품 및 심사 중인 작품
- `07-awards/winners/`: P LAB 교육생·후계 창작자의 수상·본선 진출·공식 선정작
- `99-archive/`: 홈페이지에서 현재 사용하지 않는 이전 영상

영상 썸네일·대표 이미지·커버 이미지는 `public/posters/`에 넣습니다.

## R2 배포 기준

`public/videos/`가 사이트 카탈로그와 R2 업로드의 단일 기준 원본입니다.
폴더는 영상의 대표 카테고리이자 R2 저장 경로입니다. 하나의 영상이 여러
카테고리에 해당하면 파일을 복제하지 않고 `data/video-category-overrides.json`에
카테고리를 추가합니다. R2용 복사 폴더에 별도로 영상을 배치하지 않습니다.

```bash
npm run catalog
npm run r2:upload
```

`r2:upload`는 현재 폴더 경로를 그대로 R2 키로 사용하므로, 사이트가 요청하는
경로와 업로드 경로가 항상 일치합니다.

## 화면비 관리

영상 방향 때문에 카테고리 폴더를 다시 나누지는 않습니다. 웹사이트가 영상의
실제 가로·세로 크기를 읽고 다음 세 가지 레이아웃으로 구분합니다.

- `LANDSCAPE`: 가로형. 기본 16:9 시네마 프레임
- `PORTRAIT`: 세로형. 9:16 포트레이트 프레임
- `SQUARE`: 정방형. 1:1 갤러리 프레임

현재 라이브러리 검사 결과는 `ASPECT-RATIOS.md`에서 확인할 수 있습니다.

### 디자인 원칙

- 세로 영상을 16:9 프레임에 확대해서 좌우나 인물을 잘라내지 않습니다.
- 목록에서는 가로형을 넓은 카드, 세로형을 좁고 높은 카드, 정방형을 1:1 카드로
  구성해 편집된 매거진 그리드처럼 배치합니다.
- 실제 영상 재생 화면은 항상 원본 화면비를 유지하고 `object-fit: contain`을
  사용합니다.
- 빈 공간은 검은색·은은한 그레인·작품 메타데이터로 구성하며 흐린 복제 영상을
  억지로 배경에 채우지 않습니다.
- 포스터는 각 영상의 화면비와 동일하게 제작합니다. 목록용으로 별도 크롭이
  필요하면 원본 포스터를 덮어쓰지 않고 `-card` 파일을 추가합니다.
- 카드에 `16:9`, `9:16`, `1:1` 배지를 작게 표시해 화면비를 작품 정보로
  활용합니다.

## 파일명 규칙

영문 소문자와 하이픈만 사용하는 것을 권장합니다.

```text
프로젝트명-버전-해상도.확장자
```

예시:

```text
night-drive-v01-1080p.mp4
night-drive-depth-v01-1080p.mp4
night-drive-web-v01-720p.mp4
night-drive-poster-v01.webp
```

## Hero Depth 영상 권장 사양

- 길이: 6~12초
- 형식: MP4 / H.264
- 화면비: 16:9
- 권장 해상도: 1920×1080 원본
- 프레임레이트: 24 또는 30fps
- 오디오: 없어도 됨
- 첫 프레임과 마지막 프레임이 자연스럽게 이어지는 루프 권장

Depth 처리를 원하는 영상은 우선 `00-hero-depth/source/`에 넣습니다.

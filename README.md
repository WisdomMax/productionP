# Production P — full website source

## Included
- Next.js + React + TypeScript
- Real React Three Fiber / Three.js WebGL scene
- GSAP ScrollTrigger
- Lenis smooth scrolling
- FRAME 000 → 240 cinematic loader
- Generated local cinematic image assets in /public/assets
- WORK / AWARDS / P LAB / JOURNAL / CONTACT
- Work detail route
- Journal detail route
- Markdown content samples
- SEO metadata + JSON-LD
- Standalone `preview.html` using real Three.js WebGL, GSAP and Lenis from CDN

## Run the Next.js version
```bash
npm install
npm run dev
```

Then open http://localhost:3000
